 Lumina Skin & Beauty 

Lumina Skin & Beauty is a makeup and skincare recommendation website that helps users discover beauty products and routines that may suit their skin type. It focuses on three profiles: Oily Skin, Dry Skin, and Sensitive Skin. Its interactive features make skincare information and makeup suggestions easier to explore.

 FEATURES
- Interactive Skin Analyzer – Users can use their live camera or upload a photo for a skin analysis experience.
- Skin Type Selection – Users can manually choose an oily, dry, or sensitive skin profile.
- Personalized Makeup Recommendations** – Explore makeup products and formulations suggested for each skin type.
- Skincare Routines – View suggested morning (AM) and evening (PM) skincare routines.
- Makeup Application Guide – Learn application techniques, professional tips, and products or ingredients to avoid.
- Responsive Design – Browse through a clean and elegant layout designed for different screen sizes.

 TECHNOLOGY USED
- HTML5 – Provides the website's structure and content.
- CSS3 – Handles styling, layout, and responsive design.
- JavaScript – Supports interactive features, skin analysis, and dynamic recommendations.

PROJECT STRUCTURE
- `index.html` – Contains the main website structure and content.
- `styles.css` – Defines the website's visual design and layout.
- `app.js` – Handles interactive functions and recommendations.

 PROJECT PURPOSE
Lumina Skin & Beauty aims to provide an accessible platform where users can learn about their skin type and explore makeup and skincare suggestions that may match their needs. By combining skin type selection, product recommendations, skincare routines, and makeup guides in one place, the website helps make beauty information easier to understand. It also encourages users to make informed choices when exploring products and learning about their personal beauty needs and developing a simple daily beauty routine.

 DISCLAIMER
This website is intended for educational and informational purposes only. Skin analysis and product recommendations are general suggestions, not a substitute for professional dermatological advice. Users should consult a qualified skincare professional when necessary.
